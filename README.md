# Prompt Refiner 🎯

**Prompt Refiner** is an AI prompt refinement Chrome extension that turns vague or simple prompts into structured, highly optimized prompts for models like Claude, GPT-4o, Gemini, DeepSeek, and Groq.

## ✨ Features

- **Multi-Provider AI Support**: Claude, OpenAI, Google Gemini, OpenRouter, and Groq.
- **Preset Modes**: Standard, Creative, Technical, Structured, Minimal, and more.
- **Side-by-Side Comparison**: Easily view the original input vs refined prompt.
- **One-Click Copy & History**: Quickly access previously refined prompts.
- **Privacy First**: Your API keys are stored locally in your browser storage.

## 🚀 Installation

1. Clone or download this repository:
   ```bash
   git clone https://github.com/rajendra-18git/prompt-refiner.git
   ```
2. Open Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** (top right toggle).
4. Click **Load unpacked** and select the `prompt-refiner-extension` folder.
5. Click on the extension icon to start refining prompts!

## 🛠️ Tech Stack

- Manifest V3 Chrome Extension
- Vanilla JavaScript & CSS
- Local Chrome Storage API
